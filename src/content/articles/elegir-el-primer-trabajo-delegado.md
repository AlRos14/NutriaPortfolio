La primera responsabilidad de un agente no depende necesariamente del tamaño de la empresa. Puede aparecer en un puesto, un equipo o varios departamentos: información que necesita ordenarse, asuntos que requieren seguimiento o consultas que deben atenderse con fuentes concretas.

El punto de partida es una necesidad reconocible. Para elegirla, conviene entender el trabajo antes de decidir qué herramientas se habilitan o qué nombre tendrá el agente.

## Describe el trabajo como se realiza hoy

Identifica de dónde llega la información, quién la utiliza y qué resultado necesita el equipo. Si el trabajo pasa por varios sistemas, señala cuáles contienen los datos relevantes y qué acciones se realizan en cada uno.

No se trata de documentar cada clic como un procedimiento obligatorio. Se trata de que el objetivo, las fuentes y las decisiones estén claros. Esa descripción ayuda a distinguir qué puede delegarse y qué necesita una intervención concreta.

## Elige un resultado observable

Un resumen, un borrador o una relación de asuntos pendientes permiten revisar el resultado de forma directa. Un encargo como «mejora la administración» necesita concretarse antes de evaluar si se ha cumplido.

**Ejemplo ilustrativo:** revisar un conjunto de documentación autorizada y preparar un resumen para una reunión. El equipo puede valorar si el resumen responde a la pregunta, utiliza las fuentes indicadas y explica las limitaciones. Este ejemplo no garantiza que la integración documental de una empresa esté disponible sin configuración.

## Revisa qué puede hacer el agente

Para cada resultado, define qué información puede consultar y qué efectos tiene permitido producir. Un agente que prepara un borrador no necesita necesariamente permiso para publicarlo. Otro rol puede tener autorización para ejecutar ciertas acciones sin solicitar aprobación en cada paso.

Las capacidades concretas dependen de las herramientas habilitadas, los plugins y el alcance acordado. El interés de un caso de uso no demuestra por sí solo que toda la configuración necesaria esté lista.

## Decide quién resuelve las dependencias

Un dato que falta o una decisión no delegada pueden requerir a una persona. Conviene saber a quién se consulta y qué información necesita para responder. Esa intervención tiene un propósito concreto dentro del trabajo.

Antes de ampliar el alcance, revisa el resultado y los asuntos pendientes. Una valoración útil distingue el trabajo realizado de lo que aún depende de fuentes, permisos o decisiones. No necesita apoyarse en una promesa de ahorro ni en una cifra de productividad inventada.
